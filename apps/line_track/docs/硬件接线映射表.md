# car 硬件接线映射表

> 主控：**MSPM0G3507** · 板型：**LCKFB-TMX**  
> 依据：`syscfg/ti_msp_dl_config.h`、`syscfg/app.syscfg`、`docs/pins.md`  
> 更新：2026-07-31

## 1. 车体轮位

```text
        前进
    ┌─────────┐
    │ B    C  │   左前 B · 右前 C
    │         │
    │ A    D  │   左后 A · 右后 D
    └─────────┘
```

| 侧 | 轮 | 电机 | 编码器 |
|----|----|------|--------|
| 左 | 前 | Motor B | EncB (E2) |
| 左 | 后 | Motor A | EncA (E1) |
| 右 | 前 | Motor C | EncC (E3) |
| 右 | 后 | Motor D | EncD (E4) |

- 左 = A + B，右 = C + D  
- 线速度：+前 −后；转向：+左 −右  
- 极性 / 配平见 `src/Function/Inc/chassis_cfg.h`（`POL_*`、`LEFT_TRIM` / `RIGHT_TRIM`）

## 2. 直流电机（TB6612 类驱动）

| 功能 | MCU 引脚 | 外设 / 类型 | SysConfig 宏 | 备注 |
|------|----------|-------------|--------------|------|
| Motor A PWM | **PA12** | TIMG0 CCP0 | `GPIO_PWMA_C0` | 左后 |
| AIN1 / AIN2 | **PB13 / PB15** | GPIO DOUT | `GPIO_MOTOR_AIN1/2` | 方向 |
| Motor B PWM | **PA21** | TIMG6 CCP0 | `GPIO_PWMB_C0` | 左前 |
| BIN1 / BIN2 | **PB4 / PB6** | GPIO DOUT | `GPIO_MOTOR_BIN1/2` | 方向 |
| Motor C PWM | **PA13** | TIMG0 CCP1 | `GPIO_PWMA_C1` | 右前 |
| CIN1 / CIN2 | **PB1 / PB2** | GPIO DOUT | `GPIO_MOTOR_CIN1/2` | 方向 |
| Motor D PWM | **PA22** | TIMG6 CCP1 | `GPIO_PWMB_C1` | 右后 |
| DIN1 / DIN2 | **PB3 / PB7** | GPIO DOUT | `GPIO_MOTOR_DIN1/2` | 方向 |
| STBY | **PB16** | GPIO DOUT | `GPIO_MOTOR_STBY` | H=使能，L=待机 |

**逻辑约定**

| IN1 | IN2 | 含义 |
|-----|-----|------|
| L | H | 正转 |
| H | L | 反转 |
| L/L 或 H/H | | 制动/滑行（由软件 `Chassis_Stop` 决定） |

- PWM 周期约 **4000**（≈10 kHz @ 40 MHz 定时器时钟）  
- `PWM_MAX=3800`，死区 `PWM_DEADZONE=80`（见 `chassis_cfg.h`）

## 3. 霍尔编码器（正交 · 双边沿 · 四倍频）

| 轮 | 通道 | MCU 引脚 | 中断 | 位置 |
|----|------|----------|------|------|
| A (E1) | E1A / E1B | **PB0 / PB5** | GPIOB 双边沿 | 左后 |
| B (E2) | E2A / E2B | **PB23 / PB18** | GPIOB 双边沿 | 左前 |
| C (E3) | E3A / E3B | **PB27 / PB22** | GPIOB 双边沿 | 右前 |
| D (E4) | E4A / E4B | **PB24 / PB26** | GPIOB 双边沿 | 右后 |

- 中断组：`GROUP1` / `GPIOB_INT`（`GPIO_MULTIPLE_GPIOB_INT_*`）  
- 电机：MG310，霍尔 CPR=13，减速比 30 → `ENCODER_PPR = 13×4×30`  
- 轮径 65 mm，轮距 200 mm（`chassis_cfg.h`）

## 6. 按键（外接 · 低有效）

| 功能 | MCU 引脚 | 配置 | 软件用途 |
|------|----------|------|----------|
| KEY_RUN | **PA17** | 上拉，按下=低 | 电机开/关（`Motor_SetEnable`） |
| KEY_SPD | **PA18** | 上拉，按下=低 | 开环档位 0→1000→2000→3000→0 |

- 不用板载 B21；灰度 G1–G8 脚（PB19/17、PA16/14、PB20/25、PA25/27）预留给巡线，勿占  
- 外接：按键一端接 MCU，一端接 GND

## 9. 软件对应关系

| 硬件 | 驱动 | 业务 |
|------|------|------|
| 电机 PWM + DIR + STBY | `Hardware/motor` | `Function/chassis` |
| 编码器 E1–E4 | `Hardware/encoder` | chassis odom → `lap_task` |
| 灰度 G1–G8 | `Hardware/gray` | `Function/line_track` |
| OLED SPI | `Hardware/OLED` | `main` UI |
| KEY_RUN/SPD | GPIO | `main` 电机启停 / 调速 |

数据流：

```text
KEY_RUN ──► 电机开/关
KEY_SPD ──► 开环档位
Encoder ──► OLED 周期脉冲
main ──► Motor_SetAll + OLED
```

## 10. 接线注意

1. 电机驱动电源与 MCU 地必须共地；STBY 未拉高则电机无输出。  
2. 编码器与电机同名对应（E1=A … E4=D），接线反了会出现里程符号错误（可改 `ENC_SIGN_*`）。  
3. 灰度从左到右严格对应 G1→G8，否则巡线转向符号会反（可改 `LT_TURN_SIGN`）。  
4. 极性 `POL_A/D = −1`、`POL_B/C = +1` 为实车标定结果，换驱动板后需重测。  
5. 本表与 `syscfg` 冲突时，以 **重新生成后的** `ti_msp_dl_config.h` 为准。
